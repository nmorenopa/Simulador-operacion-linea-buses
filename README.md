# 🚌 Simulador de operación de una línea de buses
Simulador en el cual se implementan diversos tipo de estructuras de datos, para atender sus requerimientos.


## Instalación
python -m venv .venv
source .venv/Scripts/activate    # Windows (Git Bash)
pip install -r requirements.txt

## Ejecutar
python app.py
